# Medicine Sorting App

Консольное приложение для сортировки объектов класса `Medicine`.
Итоговый командный проект курса Java.

## Модель

`Medicine` (Лекарство):
- `name` — название (String)
- `shelfLifeDays` — срок годности в днях (int)
- `price` — цена (int)

Объект создаётся через паттерн Builder.

## Функциональность

- Заполнение коллекции: из файла / случайно / вручную (паттерн Strategy)
- Сортировка по каждому из трёх полей (собственная реализация, без Arrays.sort)
- Поиск по коллекции (собственная реализация)
- Валидация входных данных
- Работа в цикле, выход — по выбору пользователя

## Структура пакетов

    ru.aston.medicine
    ├── model        — Medicine + Builder
    ├── strategy     — способы заполнения коллекции
    ├── sorting      — алгоритмы сортировки и компараторы
    ├── search       — алгоритм поиска
    ├── validation   — проверка входных данных
    ├── io           — чтение и запись файлов
    ├── ui           — консольное меню
    └── test         — тесты, написанные вручную

## Работа с Git

- `main` — стабильная версия, мердж в самом конце
- `develop` — основная ветка разработки
- `feat/<название>` — новая функциональность
- `fix/<название>` — исправление

Порядок: ветка от `develop` → работа → pull request в `develop` →
ревью тимлида → мердж. В конце проекта `develop` → `main`.

В `main` и `develop` нельзя пушить напрямую — только через pull request.
