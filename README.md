# Medicine Sorting App

Консольное приложение для работы со списком лекарств: заполнение, сортировка, поиск и запись в файл.

## Запуск

Требуется Java 21 и Maven.

```
mvn compile
```

Затем запустить класс `ru.aston.medicine.Main` (в IntelliJ IDEA - зеленая стрелка рядом с методом `main`).

## Тесты

```
mvn test
```

## Medicine
```name``` - название лекарства (String);

```shelfLifeDays``` - срок годности лекарства в днях (int);

```price``` - цена лекарства (double).

## Возможности

- Заполнение списка тремя стратегиями: случайно, с клавиатуры, из файла `medicines.txt`
- Три собственные сортировки: пузырьком, вставками, слиянием
- Сортировка по названию, сроку годности или цене
- Сортировка только четных сроков годности, остальные элементы остаются на своих местах
- Бинарный поиск по названию
- Подсчет вхождений лекарства в несколько потоков
- Запись списка в файл `result.txt`

## Структура

```
src/ru/aston/medicine/
    model/       - Medicine и билдер
    sorting/     - стратегии сортировки, компараторы, реестр
    strategy/    - стратегии заполнения списка
    search/      - бинарный поиск
    io/          - запись в файл
    concurrent/  - многопоточный подсчет вхождений
    validation/  - проверка ввода
    ui/          - консольное меню
test/            - тесты JUnit 5
```
